Oracle-limited matrix reproducers. These programs assert the specified language semantics and pass under odinc with exit 42. The official compiler disagrees on the asserted values for the cited defect reasons, so they are not differential fixtures and `mise run diff-test` does not scan this directory. Reproduce the official behavior with `env ODIN_ROOT=$HOME/Projects/Odin odin run <dir> -file`.

`scalar_const_multiply`: a typed constant left scalar broadcasts like every other accepted scalar side. Official folds `i32(3) * m` and `C * m` to the scaled identity `matrix[3,0;0,3]` instead of `3 * m`, because `check_binary_matrix` (`src/check_expr.cpp:4603`) keeps the stale scalar value when it retargets the operand to the matrix type and the backend short-circuits the node on that value (`lb_build_expr_internal`, `llvm_backend_expr.cpp:4667`). Correct is `matrix[3,6;9,12]` for `m = matrix[2,2]i32{1,2,3,4}`.

`row_major_dot`: row-major non-square products use the shuffle dot tree. Official indexes the right-hand matrix with the left stride in that path (`llvm_backend_expr.cpp:1195` uses `x_stride` where the column-major path at `:1144` uses `y_stride`), producing lane-shifted values at `-o:none`, NaNs at default opts, and out-of-bounds lanes for integers. Correct for the float case below is `2`; the integer product is the ordinary product.
